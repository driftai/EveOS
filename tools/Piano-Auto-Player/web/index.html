Expressive sheet timing: Adjacent notes are quick; spaces, bars and paragraph breaks add progressively longer gaps. Imported source duration/BPM scales that rhythm instead of flattening every key to one interval.

Shifted black keys get a short modifier lead so Roblox can register Shift before the note. Mixed black/white chords use a tiny stagger instead of corrupting the white keys.

Foreground mode: after Play, use the countdown to click the piano/game area so the chat textbox is not active.

Virtual Target: does not call SetForegroundWindow. It mirrors Roblox activation/focus messages inside the selected window queue, then posts the piano keys there while your real keyboard and mouse remain with Edge, Discord, or whatever window you are actually using. For the best recipient detection, click the Roblox piano once before starting, then return to your other app. This is the cleanest single-desktop experiment, but Roblox can still reject it if the client requires Raw Input or checks the real OS foreground state.

Global play speed: scales the entire sheet or recorded performance while preserving the timing shape and expressive defaults.

Transcribed sustain: audio-to-piano performances keep independent note-on/note-off timing, so one key can stay held while later notes begin. The Note gate remains the fallback for sheets and older timed performances without note-span data.

Internal play: routes the same parsed timeline to the built-in practice piano only. The selected sampled piano sound, Play, Pause, Stop, seek, chords, note holds, and global speed remain active, but no keys are sent to Roblox or any external window.

Piano layout: the practice keyboard redraws to match the selected 61-key or 88-key target. 88-key preserves A0–C8 MIDI pitches and uses the game’s Ctrl+1 through Ctrl+J out-of-range layer for the 27 edge notes.

Internal piano sound: choose an acoustic, electric, or honky-tonk sampled preset for auditioning. If a sampled preset cannot load, the tool falls back to the local Legacy Synth.
