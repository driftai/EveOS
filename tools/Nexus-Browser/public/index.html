Setup, privacy, and behavior
  1. Open ChatGPT for Windows on the conversation Nexus should use.
  2. Open PowerShell in tools\\Nexus-Browser.
  3. Copy one command above and paste it once. relay:dev automatically restores a proven binding or binds the single strong ChatGPT App target.
  4. If automatic binding is intentionally not wanted, run npm run relay:dev -- --manual-connect and use the Base Mode Connect target button.
  5. Nexus saves the full report locally, sanitizes a separate provider payload, then returns it only to the exact verified App-Origin target.

--local-only performs validation without transmitting anything to the provider.

The raw report is never exposed by the Base Mode status endpoint.
