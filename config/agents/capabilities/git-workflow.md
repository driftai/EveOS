# Git Workflow
Inspect branch, HEAD, origin alignment, and working-tree state before mutation. Preserve user-owned changes.

- Never force-push, bypass hooks, rewrite history, or discard local work.
- Commit coherent validated source changes and push non-force.
- Verify the exact remote SHA and report remaining uncertainty.
- For a bounded autonomous engineering task, `governor_prepare` may request guarded publication only when the exact mission, allowed files, protected dirty files, commit message, branch, HEAD, room, terminal, and process epoch are included in one owner-approved workflow. The agent cannot approve its own request.
