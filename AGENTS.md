# EveOS Agent Rules

The canonical repository-wide agent instructions live in [`docs/agents/AGENTS.md`](docs/agents/AGENTS.md).

Agents operating anywhere in this repository must read and follow that file before making changes. This root pointer intentionally remains for standard `AGENTS.md` discovery; do not remove it unless an equally portable repository-wide discovery mechanism is proven.

Public documentation and cross-agent roles: [`docs/README.md`](docs/README.md). The same shared rules apply to Eve, Nova, Iris (Claude Code), Astro and other contributors. Private agent instructions, sessions, credentials and machine state belong outside Git. TLO's curated public in-product identity lives under `config/agents/tlo/`; its live state does not.
